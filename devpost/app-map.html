FastAST — Application Map & Architectural Tour

High-performance, syntax-guaranteed context pruning MCP server for AI coding agents

✓ Verified Proof of Concept Ready

1. Plain-Language Overview

FastAST solves the context explosion and syntax degradation problems AI coding agents encounter when exploring large repositories. When an agent queries a large Python module (1,500–3,000+ lines), passing the full file wastes tokens and context budget. Naive line-stripping breaks indentation and triggers fatal SyntaxError crashes.

FastAST parses the file in native Rust using Tree-Sitter, applies a dual rubric (Rubric A for lexical relevance, Rubric B for syntactic anchor preservation), synthesizes indented pass placeholders for unkept bodies, counts real OpenAI BPE tokens with tiktoken-rs, and delivers guaranteed-valid Python back to the agent in under 15ms.

3. The 3-Stop Architecture Route

Stop 1: Protocol & CLI Entrypoints
python/fastast/server.py & python/fastast/cli.py

Handles the external boundary. In server.py, the prune_context tool connects via JSON-RPC stdio to Cursor and Claude Code. In cli.py, developers run instant terminal benchmarks with latency and token reduction metrics. Validates the final code string using standard library ast.parse().

Stop 2: Native Tree-Sitter AST Scope Walker & Scorer
src/parser.rs & src/scorer.rs

Parses Python source into syntax nodes in <10ms. Gathers all module imports, functions, classes, decorators, and docstring ranges. Rubric A calculates Jaccard keyword overlap against the agent's query; Rubric B guarantees 100% unconditional retention of imports and enclosing scope parent headers.

Stop 3: Deterministic Structural Repair Engine
src/repair.rs & src/lib.rs

Reconstructs the pruned code file line by line. When a function body is discarded, it synthesizes an indented pass keyword at the exact indentation depth required by Python syntax rules. Retains stacked multi-line decorators and returns telemetry metrics with verified zero syntax errors.

4. To Change This, Start Here

  • To adjust scoring sensitivity: Modify the default threshold: float = 0.5 parameter in python/fastast/server.py and python/fastast/cli.py.
  • To customize docstring retention: Inspect src/parser.rs around handle_function and src/repair.rs where docstring_rows are emitted.
  • To add new MCP tool capabilities: Add a new @mcp.tool() decorated function in python/fastast/server.py.
  • To tune release compilation speed: Adjust [profile.release] settings in Cargo.toml.

5. A Practice to Reuse

Risk-First Compiled Proving: In this project, the native bridge (Rust + PyO3 + Tree-Sitter + Maturin) was identified as the highest-risk layer in spec.md and sequenced into Slice 1. Rather than building speculative Python abstractions first, we verified native compilation and C-extension loading on step 1.

Key takeaway: When combining high-performance native libraries with high-level agent frameworks, write end-to-end mechanical verification tests against the compiled boundary immediately. Catching ABI or grammar issues early prevents expensive refactors later.
